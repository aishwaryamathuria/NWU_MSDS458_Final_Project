# Music Generation using Deep Learning

## Abstract
In this project we have explored whether a deep learning model can take a short musical input and then solve the problem of “Music Continuation” by intelligently continuing it in a coherent, stylistically-consistent manner. Unlike simple music generation systems, this project focuses on continuing to understand an existing musical phrase and continue it while preserving style, tempo, pitch patterns, and harmonic structure.
We processed the classical music dataset using concepts of NLP and then trained the LSTM network on the processed data which was used to take custom input of a classical piano phrase and extend it while keeping the style, tempo, and musical feel intact.


## Introduction
The fundamental question driving this project is: “Can a recurrent neural network, specifically an LSTM (Long Short-Term Memory) architecture, learn to meaningfully continue a short musical phrase while maintaining stylistic consistency and musical coherence?”. Musicians and composers often experience creative blocks or want to explore variations on musical themes and through this project we aim to create an AI-assisted tool that can take an input or a pre-existing musical sequence and continue on the provided piece while using the patterns and structures it has learned from a large collection of classical piano music.
We used the classical music dataset from Kaggle with 295 midi files from 19 famous composers like Schubert, Chopin, Beethoven, Mozart, and Bach. Each file was parsed with music21, where we isolated piano parts, flattened the score, and extracted notes and chords while filtering out rests and low-frequency events. To make the data more meaningful for the model, we built a filtered vocabulary by keeping only tokens that appeared at least a minimum number of times and mapping rare ones to an <UNK> token. The full token stream was then converted into overlapping sequences of 50 notes, each paired with its next-note prediction. This processed dataset was used to train our LSTM models which can then be loaded and take a short input phrase to generate a continuation in a consistent musical style.

## Methods

	The process begins by loading all 295 classical piano MIDI files and parsing them using a multiprocessing pipeline. For each file, we used music21 to extract only the piano part, flatten the score, and collect notes and chords while filtering out rests and rare events. We then built a vocabulary by keeping only musical tokens that appeared frequently enough, mapping low-frequency ones to an <UNK> token. After converting each piece into a clean token stream, we transformed the data into overlapping sequences of 50 tokens, each paired with its next-note label, creating the final training set.

The next step was to compare different LSTM architectures to see which one handled musical sequences best. We trained three versions of the model: a small LSTM, a medium LSTM, and a deeper two-layer LSTM. The small model used a 48-dimensional embedding and a single LSTM layer with 128 units, while the medium model increased the embedding to 64 dimensions and doubled the LSTM units to 256. The two-layer version kept the same embedding and units as the medium model but added a second LSTM layer to see if extra depth would help the network learn longer-range structure.

All three models were trained on the same validation split, with similar dropout, recurrent dropout, and L1 regularization settings to keep the comparison fair. Our experiments showed that adding extra depth in the two-layer LSTM did not improve performance, in fact, it slightly reduced accuracy and increased validation loss. This indicates that the additional layer did not contribute to learning new or useful features for this task. The medium LSTM, with one layer of 256 units and a 64-dimensional embedding, achieved the best balance between capacity and simplicity. It effectively captured short and mid-range dependencies while remaining computationally efficient. By selecting this medium LSTM, we maintained a “parsimonious” design where every unit and layer serves a clear purpose in learning musical structure. The network avoids unnecessary depth or complexity, ensuring interpretability and faster training, while still generating coherent, stylistically consistent continuations of input sequences.
For prediction, the trained model was given a 50 note seed extracted from the input MIDI. At every step, the model produced a probability distribution over the next possible tokens. We sampled from this distribution in place of choosing the highest value to keep the output creative and to avoid repetitive loops. Each predicted token was appended to the sequence, and the sliding window shifted forward by one step.
Finally, using our vocabulary mapping, the generated tokens were converted back into musical notes and chords to produce a playable MIDI continuation.

## Results
    
During training, the model improved quickly. The validation loss dropped from 5.04 in the first epoch to 0.4770 in the final epoch. The model reached about 89% training accuracy, showing that it had learned short and mid-range musical patterns effectively. Our training plots loss curves, accuracy curves, and checks for overfitting confirmed that the model trained steadily without becoming unstable.

To test the model we used a short Mozart excerpt (“mz_311_1_1sec.mid”). The model generated five new notes as a continuation of this phrase. These predictions reached a 39% overall similarity score with the original music, which indicates a good balance between staying stylistically consistent and creating something new.
A deeper comparison of the MIDI output gave more insight. The model produced mostly fresh melodic ideas (pitch class similarity was 5.97%, and interval similarity was 6.20%), which means it wasn’t just copying the input. At the same time, it preserved the harmonic feel well, achieving 54.7% chord similarity. The pitch range similarity of 87.23% showed that the model kept the melody in a musically appropriate register.
The results suggest that the model learned meaningful musical relationships, maintained tempo and note duration from the input, and generated playable, musically coherent continuations. One key observation was that the MIDI sounded less polished and less musical compared to the input sequence. However, even though the results were not perfect, they showed that the model was learning something meaningful rather than random noise.

## Conclusions
In this project our goal was to determine whether an LSTM could take a short musical phrase and extend it in a way that feels natural and consistent with the original piece. After preparing the MIDI dataset, selecting the best-performing architecture, and training the model, we observed that it was able to capture meaningful musical patterns and produce coherent continuations.
Across training, the medium-sized LSTM reached roughly 89% accuracy, which indicates that it successfully learned short and mid range dependencies such as melodic motion, harmonic tendencies, and common note transitions.
When tested on a Mozart excerpt, the model produced a continuation with an overall similarity score of 39%. This level of similarity shows that the model preserved the musical style and harmonic structure without simply copying the input sequence which is an important sign of genuine generative ability rather than memorization. 
The results of the project demonstrate that a carefully tuned LSTM is a strong and reliable baseline for symbolic music generation. While the model is not perfect, it consistently produced musically coherent, playable continuations and captured several aspects of classical style. This work also highlights opportunities for future improvement, such as training on longer sequences, incorporating richer tokenization strategies, or exploring transformer architectures that might capture longer-range musical structure more effectively.
